# Home Tunnel for Android 6.0.1

修复登录后出现 `Caller-provided IV not permitted`、无法保存登录状态的问题。

- AES-GCM 加密使用 AndroidKeyStore 自动生成的随机 IV，保留系统要求的随机加密保护。
- 沿用原有密钥别名和加密文件格式；已有有效登录状态可继续读取，升级无需先卸载或清除应用数据。
- 登录保存、会话凭据更新和连接缓存均使用修正后的加密流程。
- 新增 Android 8 / API 26 和 Android 15 / API 35 运行检查，覆盖真实密钥库读写、旧格式兼容、随机 IV、密文篡改拒绝，以及管理界面操作；纳入发布前必过检查。
- APK 使用原有发布证书签名，可覆盖安装 6.0.0；下载附件仍仅提供 APK。

安装 6.0.1 后重新尝试登录即可。本次修复位于 Android 本地凭据存储，不需要为此更换服务器地址或调整服务端配置。
